# Bridge Pathways: Current Program Documents

These are the current Bridge Pathways program documents, copied from the Google Drive folder "Bridge Pathways — Careers Remodel" on November 16, 2026. They are the source of truth for any Bridge Pathways work, including the website page.

Read in this order:

1. master-document.md: the whole program. Two sides, one program, every part free. Finance on one side, Careers on the other, Trades inside Careers. The Finance eight weeks are detailed here.
2. careers-program.md: the Careers side in full. One to one advising, the categories, the required advisor conversation.
3. trades.md: Trades, a branch of Careers. Apprenticeships and job placement through licensed trade partners.
4. careers-advisors.md: the current advisor list. Dave updates this as the network grows.
5. careers-application.md: the Careers application.
6. flyer-one-pager.md: the short public summary of the program.
7. advisor-one-pager.md: the short summary for advisors.

These revised documents supersede the September 2026 Bridge Pathways documents. The September version described three branches (Money, Trades, Construction), sixteen Money sessions, and one application. That structure is out of date. Do not use it.
